# 来源与交付说明

本实现基于本次用户上传的 `task-knowledge.zip`。该原包只有 `SKILL.md`、`assets/brief-template.txt`、`assets/index-template.md`，无程序源码、SQLite 数据库、实际用户存档或许可证文件。

新版 Skill 保留原有经验沉淀、独立存档、路径引用、增量合并及删除确认原则，并将索引流程替换为随包程序。原始文字的许可不作推定或变更；新增实现按 LICENSE 提供。

examples 中内容和 benchmark 的存档为专为测试编写的合成样本，不是用户历史数据。测试记录与性能报告来自交付环境中的实际执行；没有宣称已在用户机器或所有 CI 平台上运行。
